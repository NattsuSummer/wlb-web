# wlb-web

Frontend ของ **Balance Our Day**: ดูว่าตอนนี้เป็นเวลาทำอะไร ตารางวันนี้ ตารางรายสัปดาห์ สัดส่วนเวลาแต่ละหมวด ดูตารางเพื่อนในกลุ่ม และเรียนคอร์สตามลำดับ

- React + Vite + TypeScript + Tailwind
- ไทย / English · โหมดมืด / สว่าง · รองรับมือถือ แท็บเล็ต PC
- Deploy: Cloudflare Pages → `balance-our-day.pages.dev`

Backend อยู่ที่ [wlb-api](https://github.com/NattsuSummer/wlb-api)

> สถานะ: กำลังเริ่มสร้าง (เฟส 0–1)
